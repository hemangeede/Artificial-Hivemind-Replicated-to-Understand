# Artificial Hivemind: Replicated to Understand

A replication project based on the research paper **"Artificial Hivemind: The Open-Ended Homogeneity of Language Models (and Beyond)."** This project aims to understand and replicate the paper's methodology for analyzing the homogeneity of language models in open-ended generation.

## INFINITY-CHAT Dataset

The original research introduces the INFINITY-CHAT collection for studying open-ended language model generations and their diversity.

The dataset provides a resource for investigating similarities and differences in the responses generated by language models.

## Code Implementation and Replication

The `hivemind.py` script implements a replication of selected components of the original research methodology.

### Key Implementation Details

- **Offline Execution:** The script is designed to run offline without requiring an external text-embedding API.
- **Text Similarity:** TF-IDF is used as an alternative to the `text-embedding-3-small` embedding model used in the original approach.
- **Input Data:** The current implementation uses hard-coded data for demonstration and replication purposes.
- **Structured Output:** The output is organized in a structured format to facilitate further analysis.
- **Extensibility:** The implementation can be extended to load collected or dataset-derived data from JSON files and structure the outputs according to the requirements of the language models being evaluated.

### Implementation Notes

TF-IDF provides a lightweight, locally executable approach for measuring lexical similarity. However, it does not capture semantic similarity as effectively as contextual text embeddings.

Therefore, results obtained using TF-IDF may differ from those produced by the original embedding-based approach. This implementation should be understood as a replication or approximation of selected components rather than an exact reproduction of the original system.

## Evaluation

The evaluation metrics and methodology are based on the concepts presented in the original research paper and the accompanying presentation.

The replication aims to explore these evaluation approaches using a locally executable implementation.

**Note:** Because the implementation uses TF-IDF instead of the original embedding model, the resulting similarity measurements and evaluation outcomes may not be directly comparable to those reported in the paper.

## Project Objectives

The main objectives of this project are to:

1. Understand the methodology proposed in the *Artificial Hivemind* research paper.
2. Explore approaches for evaluating homogeneity and diversity in language model outputs.
3. Implement selected components of the methodology using locally executable Python code.
4. Investigate the use of TF-IDF as an alternative to API-based text embeddings.
5. Develop an extensible pipeline that can process collected or dataset-derived data.
6. Understand the limitations and trade-offs involved in replicating a research methodology with alternative similarity measures.

## Limitations

- The current implementation uses hard-coded input data.
- TF-IDF replaces the original embedding-based similarity approach.
- The replication may not reproduce the original paper's results exactly.
- Further work is required to evaluate the implementation on larger datasets and compare its results against the original methodology.

## 🔮 Future Improvements

Potential improvements include:

- Loading input data dynamically from JSON files.
- Evaluating the implementation on data derived from INFINITY-CHAT.
- Integrating sentence or text embeddings for semantic similarity analysis.
- Comparing TF-IDF-based results with embedding-based results.
- Extending the pipeline to support multiple language models.
- Conducting systematic evaluations against the metrics and experimental settings described in the original paper.
